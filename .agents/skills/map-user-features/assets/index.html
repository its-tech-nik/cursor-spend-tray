How to read coverage

This measures how much of the app’s Python API surface the capability map points at — not line-by-line test coverage, and not “how complete the product is.”

N/M (P%)
Unique class / def symbols under src/cursor_spend_tray/ that appear in at least one map code reference, divided by all such definitions (nested helpers inside functions are excluded). The bar tracks this percentage. Low % is normal: most defs are internal plumbing the map intentionally skips.
A/B code refs matched
How many map code entries resolve to a real definition. A miss usually means a constant, renamed symbol, or stale line — not that a user feature is missing.
class · function · method
The same definition-coverage split by kind. Use it to see whether the map mostly hits UI classes/methods vs free functions.
